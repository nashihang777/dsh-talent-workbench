# 补齐理论深度

> 维度技能 `talent-dimension-theory-depth` · 版本 v1 · 本地存储 · 可回溯

## 考察目标

判断候选人能否在数学/物理/材料理论层面提升建模深度：第一性原理、分子动力学、数值算法、热力学/相图等。

## 何时使用

需要从机理层提升预测模型、需要判断近似条件与误差来源时使用；纯工程岗可降低权重。

## 判定方法

1. 识别候选人使用的方法层级：第一性原理、分子动力学、相图/热力学、数值 PDE、优化理论、统计学习理论等。
2. 区分「会用软件」与「能建模」：能否写出方程、说明近似、选择边界条件、推导误差、用实验/更高精度计算验证。
3. 判断该理论能力是否对准团队的建模瓶颈（例如稀土永磁的电子结构、萃取界面、过程场预测）。
4. 记录证据：推导、代码、验证对象、精度/误差、独立负责部分。
5. 只有课程、只会点软件、或理论工作与岗位对象无关时判「否」。

## 证据清单

- 理论方法、方程/模型、近似条件、数值实现。
- 与实验或高精度计算的对照验证。
- 本人在推导/代码/验证中的独立贡献。
- 与岗位建模瓶颈的具体接口。

## 分级标准

| 等级 | 分值 | 判定口径 |
|---|---|---|
| 是 | 1 | 存在明确、可命名的能力接口。 |
| 否 | 0 | 不存在该接口，或属于团队已有核心方向。 |

## 反偏差与反幻觉

理论深度不等于学历或专业名称。数学、物理背景只有在能对接岗位建模瓶颈时才计分；材料/化学背景也不能因为「做过计算」就自动判「是」。

## 面试追问

- 你推导或实现了哪部分方程？近似条件是什么？换体系后哪些假设会失效？
- 你如何验证计算/模型的误差？和实验对上了吗？
- 如果让你把机理层接入我们的材料预测模型，第一步做什么？

## 输出格式

是/否、方法清单、推导/实现证据、验证方式、与瓶颈的接口、置信度。

## 校准建议

若团队已有理论计算负责人，本维度可降到 5% 以下；若当前最缺机理层，可提高到 15% 左右，但需配合学术水平一起看。

## 使用约束

本技能只服务于本地筛选与面试准备，不得把候选人姓名、联系方式、简历原文或任何可识别个人的信息写入交换包。判级必须引用证据；证据不足时降低置信度，不得编造。
