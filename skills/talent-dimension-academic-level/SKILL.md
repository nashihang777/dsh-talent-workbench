# 学术水平预估

> 维度技能 `talent-dimension-academic-level` · 版本 v1 · 本地存储 · 可回溯

## 考察目标

按已发表/已接收成果的层级与作者位次，预估当前学术水位；在投、在审单独列出，不计入已发表。

## 何时使用

研究型岗位、需要独立课题能力或学术能见度的岗位；工程执行岗可降低权重。

## 判定方法

1. 只统计已发表或已接收成果；在投、在审、在修、返修全部单列，不折算为已发表。
2. 只统计第一作者与共同第一作者；导师一作、学生二作、三作单列为「参与」。共同一作按 0.5 篇折算，并在证据中注明。
3. 把期刊/会议映射到层级：CNS 及子刊/顶刊、JCR Q1 TOP、Q1、Q2、CCF-A/B/C、EI、北大核心。以简历自述为线索，标注「待核验」。
4. 用「最好的 2—3 篇 + 总量」判级，不用简单 IF 求和；不同学科的影响因子不可直接横比。
5. 记录核验缺口：作者位次、接收函、DOI、预警期刊、增刊等。

## 证据清单

- 论文题目、期刊/会议、年份、作者位次、发表状态。
- 接收函/DOI/预印本链接（本地记录即可，不上链）。
- 共同一作的署名说明与个人贡献。
- 专利、标准、软件著作权作为补充，不替代论文层级。

## 分级标准

| 等级 | 分值 | 判定口径 |
|---|---|---|
| 高 | 1 | 直接命中岗位核心问题，且已有可验证的独立产出。 |
| 中上 | 0.8 | 核心一侧较强，另一侧可迁移，短期补齐成本低。 |
| 中 | 0.6 | 有可迁移的方法或平台能力，需要换体系验证。 |
| 中下 | 0.4 | 只有工具级或间接相关经验，独立支撑能力弱。 |
| 低 | 0.2 | 与岗位问题链没有可用接口。 |

## 反偏差与反幻觉

学术水平只回答「已经发表到什么层级」，不回答「未来能不能成长」。不要把平台、导师名气、学校层级折算成个人学术水平；也不要用年龄或第一学历替代成果证据。

## 面试追问

- 请给出三篇代表作的具体作者位次、投稿状态和你的贡献；在投的请出示投稿系统截图。
- 这篇共同一作中，你和另一位一作分别负责什么？
- 为什么选择这个期刊？它在你所在领域的实际层级如何？

## 输出格式

等级、已发表一作数、共同一作数、最佳刊物、在投清单、核验缺口。

## 校准建议

若岗位核心是工程交付，本维度权重可降到 10% 以下；若岗位需要课题负责人，建议保持在 18%—25%。

## 使用约束

本技能只服务于本地筛选与面试准备，不得把候选人姓名、联系方式、简历原文或任何可识别个人的信息写入交换包。判级必须引用证据；证据不足时降低置信度，不得编造。
