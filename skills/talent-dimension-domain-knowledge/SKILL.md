# 领域知识与行业经验

> 维度技能 `talent-dimension-domain-knowledge` · 版本 v1 · 本地存储 · 可回溯

## 考察目标

考察目标行业的知识深度与可迁移性：工艺/业务链条、术语、合规约束与典型失败模式，而不只是「待过这个行业」。

## 何时使用

所有需要行业 know-how 的岗位（制造、能源、医疗、金融、材料、汽车电子等）；通用平台岗可降低权重。

## 判定方法

1. 让候选人用行业语言讲清一条完整业务链：输入、关键工序/环节、输出、常见的质量或风险指标。
2. 追问失败模式：这个行业最典型的坑是什么，为什么会踩，怎么避免。
3. 区分「在行业里工作过」与「理解行业约束」：后者能说出为什么某些通用方案在这里不成立。
4. 看合规与标准：涉及医疗、金融、能源时，检查对法规与标准的熟悉度。
5. 评估可迁移性：相邻行业的经验需要多长时间补齐，缺的是知识还是人脉。

## 证据清单

- 行业项目中的具体环节与个人职责。
- 对工艺/流程/业务链的准确描述与量化指标。
- 对失败案例与行业约束的理解。
- 相关标准、法规、认证经验。

## 分级标准

| 等级 | 分值 | 判定口径 |
|---|---|---|
| 高 | 1 | 在真实生产/一线环境中独立做到，且有可验证结果。 |
| 中上 | 0.8 | 有完整实践与量化结果，复杂度或规模略低。 |
| 中 | 0.6 | 做过同类事情但以参与为主，或停留在非生产环境。 |
| 中下 | 0.4 | 有课程/实习级接触，缺少独立交付证据。 |
| 低 | 0.2 | 没有相关证据，或只有名词级了解。 |

## 反偏差与反幻觉

不要用「在某某行业待过几年」直接判高；也不要因为跨行业就判低，要看他是否理解约束与失败模式。

## 面试追问

- 用你们的行业语言讲一遍这条业务链：从输入到交付，哪一步最容易出问题？
- 你们行业最典型的一次事故/召回/处罚是什么原因？你从中学到什么？
- 如果把你放到相邻行业，你需要多久补齐？缺的是什么？

## 输出格式

等级、业务链准确度、失败模式理解、合规与标准、迁移成本、缺口。

## 校准建议

行业岗 15%—25%；通用平台岗 5%—10%；跨行业招聘时把权重放在学习迁移上更合理。

## 使用约束

本技能只服务于本地筛选与面试准备，不得把候选人姓名、联系方式、简历原文或任何可识别个人的信息写入交换包。判级必须引用证据；证据不足时降低置信度，不得编造。
